# Minimal Link in Bio

A clean, responsive mobile-first link-in-bio landing page built with semantic HTML5 and modern CSS.

## Features
- Minimalist profile header with avatar card and bio
- Responsive link list with hover animations and click interactions
- CSS custom properties (variables) for theme styling
- Mobile-first responsive layout (optimized for all screen sizes)

## Preview
Open `index.html` in your browser.
